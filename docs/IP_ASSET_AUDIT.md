## 1. Artwork — 100% original, 100% reproducible

Everything in `public/art/` is generated by `npm run assets` from two hand-authored
source files:

| Source | What it contains |
|---|---|
| [`scripts/lib/pixel-font.mjs`](../scripts/lib/pixel-font.mjs) | An original 5×7 bitmap font, drawn glyph by glyph as character strings. Used for all lettering inside generated artwork. |
| [`scripts/lib/sprites.mjs`](../scripts/lib/sprites.mjs) | Original pixel sprites as colour-keyed character grids. |

Because the artwork is *generated*, there is no binary blob whose provenance has to be
taken on trust — delete `public/art/` and re-run `npm run assets` to rebuild it exactly.

### Sprites

| Sprite | Description | Resemblance check |
|---|---|---|
| `PLAYER_ONE` | Hooded figure holding a cartridge | Generic archetype. No resemblance to any protected character. |
| `MARKET_BOSS` | Suited figure whose head is a screen showing candlesticks | Original concept. Not derived from any existing character. |
| `ATTENDANT` | Striped arcade referee | Generic occupational figure. |
| `COIN` | Circular token | Generic. Deliberately not a ring, a star, or any franchise collectible. |
| `MINI_CART` | Small cartridge shell | Generic cartridge silhouette — a functional shape, not any manufacturer's trade dress. |
| `CORRUPT_SAVE` | Floppy-disk glyph with glitch bars | Generic storage-media icon. |

### Generated files

## 2. Fonts — all OFL 1.1, self-hosted

| Family | Weight | File | Licence | Role |
|---|---|---|---|---|
| Press Start 2P | 400 | `press-start-2p-400.woff2` (4.6 KB) | SIL OFL 1.1 | Pixel display |
| VT323 | 400 | `vt323-400.woff2` (7.0 KB) | SIL OFL 1.1 | Terminal / boot readout |
| Anton | 400 | `anton-400.woff2` (11.7 KB) | SIL OFL 1.1 | Poster headlines |

| IBM Plex Mono | 600 | `ibm-plex-mono-600.woff2` (9.9 KB) | SIL OFL 1.1 | Emphasis in data |

Total: **52 KB**, Latin subset only. Fetched by `node scripts/fetch-fonts.mjs`, which
records the exact upstream URLs in `public/fonts/SOURCES.json`.

The SIL Open Font License explicitly permits bundling and redistribution. Self-hosting
also means the site makes **zero third-party requests**, which is what allows the strict
CSP in `index.html`.

A fifth "font" — `--font-ugly` — is the system `Times New Roman` stack. Nothing is
downloaded for it.

## 3. Audio — nothing to license

There are **no audio files in this project.** Every sound is generated at runtime from
WebAudio oscillators and a deterministically-seeded noise buffer in
[`src/audio/audio-engine.ts`](../src/audio/audio-engine.ts).

This deliberately avoids the most common IP trap in retro-styled sites: bundling ripped
game SFX or a chiptune track. There is nothing here to be taken down.

## 4. Third-party names — factual use only

The site names other companies. Each use is nominative and factual:

| Name | Where | Why it is permissible |
|---|---|---|
| **GameStop** | "GME stock token", `name()` output, disclosures | Factual identification of the asset the pool is quoted in. Every appearance is adjacent to a statement that this project is not affiliated with and not endorsed by GameStop, and that the token is not GameStop stock. |
| **Robinhood** | Network name, "Robinhood Chain", stock-token issuer | Factual identification of the network and issuer. Explicitly disclaimed in the footer. |
| **Uniswap** | "Uniswap v4 pool" | Factual description of where liquidity graduates to. |
| **Pons** | Launchpad name | Factual identification of the launch venue. |
| **Nintendo, Sega, Sony** | Footer disclosure only | Named **only** to disclaim affiliation. They appear nowhere else. |

### What is deliberately absent

- ❌ No Nintendo/Sega/Sony logos, wordmarks, console trade dress, or UI chrome.
- ❌ No Mario, Luigi, Zelda, Pokémon, Kirby, Donkey Kong, Sonic, Crash Bandicoot, or any
  other protected character — including as "inspiration" for a sprite.
- ❌ No GameStop logo, store photography, proprietary typeface, or marketing artwork.
- ❌ No ripped sprites, sound effects, soundtracks, box art, or screenshots.
- ❌ No content from cbkswwc.com. The reference site was studied for **design grammar
  only** (density, dialog-driven opening, marquees, collage layering). No copy, artwork,
  GIF, CSS, markup or animation timing was copied from it. See `DESIGN_SYSTEM.md` for how
  the influence was translated rather than transcribed.

### Trade-dress note

The cartridge motif is a *generic* cartridge: a rectangular shell, ridged grip, label
plate, and edge connector. These are functional features common to dozens of
manufacturers, drawn from scratch at pixel resolution. It is not modelled on any
particular manufacturer's shell shape, colour scheme, or label layout.

## 5. Replacement manifest

Nothing here is a placeholder awaiting a licensed replacement. Two items are
**provisional branding** that the operator is expected to replace with their own:

| Item | Current | Replace by |
|---|---|---|
| Project name | `CARTRIDGE 4663` | `VITE_PROJECT_NAME` |
| Ticker | `CART` | `VITE_TOKEN_SYMBOL` |

## 6. Verdict

**Nothing in this repository is blocked, and nothing requires a licence beyond the SIL
OFL already satisfied by bundling the font files.** The project can ship as-is from an
asset-rights standpoint.

Legal review is still recommended for the *securities and marketing* language in
`src/config/content/disclosures.ts` — that is a different question from asset rights and
is flagged in `QA_REPORT.md`.
