SVG compresses extremely well because the artwork is thousands of repeated `<rect>`
elements — 551 KB of markup becomes 41 KB on the wire.

## Regeneration

```bash
npm run assets              # every SVG in public/art/, plus the gallery manifest
node scripts/rasterize.mjs  # the five PNGs, from the SVGs above
node scripts/fetch-fonts.mjs # re-fetch the Latin-subset font files
```

`npm run assets` also writes `src/config/content/gallery.generated.json`, which is what
the evidence-reel section reads — so a poster cannot be added to the gallery without also
being given alt text in the generator.

## Replacement status

Nothing here is a placeholder awaiting a licensed asset. Two items are **provisional
branding** for the operator to replace:

| Item | File | How to replace |
|---|---|---|
| Logo mark | `art/logo-mark.svg` + the four PNG icons | Edit `logoMark()` in `scripts/generate-assets.mjs`, then `npm run assets && node scripts/rasterize.mjs` |
| Social card | `art/social-card.svg` + `social-card.png` | Edit `socialCard()`, same regeneration |

## Source files

The artwork has no binary source — it is generated from two hand-authored modules:

| File | Contents |
|---|---|
| `scripts/lib/pixel-font.mjs` | Original 5×7 bitmap font, one glyph per character-string block |
| `scripts/lib/sprites.mjs` | Original pixel sprites as colour-keyed character grids |

Delete `public/art/` entirely and `npm run assets` rebuilds it byte-for-byte.
